## Kompozitsiya
- **Spiker deyarli butun ekranda** (katta mikrofon, yashil halqa chiroq). Ustki yarmida **qorong‘i oyna-overlaylar** paydo bo‘ladi va yo‘qoladi — ekran bo‘linmaydi, kartalar spiker ustida suzadi.
- **Subtitr:** 2–3 so‘z, oq qalin, qora kontur; kalit so‘z coral («напиши **гитхаб**»). Ba’zan butun ekran coral fon + intervyu klipi.

## Sahnalar
- **Brauzer:** GitHub logotipi → `github.com/garrytan/gstack` manzili zoom qilinadi, kursor bilan nusxalanadi → **Claude Code terminali**ga qo‘yiladi: «установи этот репозиторий».
- **Piksel maskotlar jamoasi:** coral piksel Claude maskotlari toj, shlyapa, ko‘zoynak kiygan — **dumaloq stol atrofida** («CEO, dizayner, menejer, QA» — muhandislar jamoasi). Neon Jamoa (6-namuna) g‘oyasining piksel varianti.
- **Kim yaratgan:** Google qidiruvi «Гарри Тан» rasmlari → README («23 opinionated tools…»), to‘q sariq fonda intervyu klipi + **Y Combinator** logotipi.
- **Nima qiladi:** kod muharriri **qizil X** bilan o‘chiriladi («kod yozmaydi») → papka daraxti `my-app/src/components…` (rejalashtirish) → dizayn tizimi kartalari (Aa, rang namunalari, tugmalar — «tekshiradi») → bo‘sh hujjat «Документация проек|» yoziladi → test checklist: Вход по почте ✓, Регистрация ✓, Оплата картой ✓, Загрузка файла (spinner → ✓).
- **Isbot:** «**135.7k stars**» sariq ramka bilan zoom qilinadi.
- **Terminal:** `Skill(plan-ceo-review)` va `Skill(plan-eng-review)` ishlayapti.
- **CTA:** «напиши **гитхаб** в комменты — скину ссылку».
