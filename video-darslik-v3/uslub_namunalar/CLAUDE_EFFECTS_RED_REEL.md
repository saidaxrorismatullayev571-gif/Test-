# «Comment CLAUDE for every prompt» — qizil xona, effektlar (tahlil)

**Manba:** foydalanuvchining 11-namunasi. 720×1280, 30 fps, 30,5 s, ovozli. **Kadrlar:** `claude_effects_red_1.jpg`.
**Tuzilma:** Claude iOS ilovasi (soat 9:41, holat paneli bilan), `/effect` buyrug‘i yoziladi → «Editing with /…» → piksel-mozaika dissolve → natija ilova ichidagi kartada (to‘liq ekran emas). Klip: yigit, qora fon, **qizil neon** shift. Effekt nomi pastda ikki qatorda: oq qalin «liquid glass graph» + kursiv serif «*with one prompt*». Yakun: «Comment **CLAUDE**» (CLAUDE coral) + coral pill «for every prompt» + 3×3 natija to‘ri.

## Yangi effektlar (oldingi effekt reellarida yo‘qlari)
| Buyruq | Ko‘rinishi |
|---|---|
| `/over-the-shoulder` (zoom) | Bosh yonida oq kartalar «BEFORE 1,204» → «AFTER 397K → 412K» (yashil nuqta), kamera yuzga sekin zoom |
| `/glass-graph` | Ko‘krak oldida suyuq shisha karta «WATCH TIME 31% → 68%», yashil o‘sish chizig‘i, nuqta yonadi |
| `/freeze-frame` | Kadr to‘xtaydi, fon kulrang bo‘ladi, odam **oq stiker kontur** bilan kesib olinadi, pastida ism tegi «Liam · CREATOR» (oq kapsula). «Odamni tanishtirish» uchun |
| `/tier-list` | Shisha panelda S/A/B/C/D reyting qatorlari (rangli harf kataklari), AI vosita logotiplari tepadan tushib qatorlarga joylashadi |
| `/text-behind` | Ulkan oq qalin so‘z «VIRAL» odam **ortida** (pastdan ko‘tariladi) |
| `/color-grade` | Vertikal wipe chizig‘i: chapda «AFTER», o‘ngda «BEFORE» |

## Bizga foydali xulosalar
- **freeze-frame + ism tegi** — darsda spiker yoki qahramonni tanishtirish uchun juda yaxshi (Rejabboyev: «Arabboy Rejabboyev · HR mutaxassisi»).
- **tier-list** — taqqoslash/reyting mavzulari uchun: «KPI turlari: S — tushum, A — konversiya…».
