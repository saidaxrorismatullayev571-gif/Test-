# «Use this. → to get this.» — bitta klip, ko‘p uslub (tahlil)

**Manba:** 31-namuna (@ME.YEBI, ingliz tilida). 1080×1920, 30 fps, 15,7 s, ovozli. **Kadrlar:** `use_this_get_this_1.jpg`.

## Kompozitsiya (juda tez, ~0,6 s har variant)
- **Qora fon.** Yuqori-markazda telefon kartasi — **bitta klip** (yigit gapiradi: «Did you know the first song…»), har kadrda boshqa uslubda.
- **Chapda** kichik serif yozuvlar navbatma-navbat: «Use **this.**» → «to get **this.**» — prompt va natijani bog‘laydi.
- **Pastda** Claude Desktop oynasi «✳ Hello, night owl»: har variantda yangi prompt yoziladi (model «Opus 5.5»).

## Ko‘rsatilgan subtitr/overlay uslublari (bir klipda)
1. **Marker-highlight kursiv serif:** «*Did you know*» — ko‘k marker fonida oq kursiv, ostida kichik so‘zlar.
2. **Brend-UI integratsiyasi:** **Apple Music pleyeri** — «First song · a computer» kartasi, pleyer tugmalari, ostida klip (gapdagi mavzu — birinchi qo‘shiq — mahsulot UI orqali ko‘rsatiladi).
3. Qora fonda katta **Apple Music** logotipi + kursiv izoh «Did you *know*?».
4. **«N°1»** to‘q sariq qiyshiq karta (reyting/chart).
5. **Oq UI kartasi** (ilova oynasi, ko‘k nuqta pleyer, burchakda «#1» belgisi) — kalit so‘z ko‘k/to‘q sariq rangda subtitrda.
6. **3D qiyshaygan logotip plitasi** «Apple Music» kulrang va oq fonda.
7. Oq fon + kichik minimal subtitr «the first».
- **Yakun:** qora fonda serif so‘zlar bittadan: «want» → «editing» → «skills?» → Telegram yuborish tugmasi + «SKILL» pill → yashil chaqnash → **«SKILL.MD»** pill → Instagram logotipi.

1. **«Use this → get this»** — bitta xom klipdan ko‘p uslub chiqarish mumkinligini 15 soniyada ko‘rsatadi. Bizda: bitta dars parchasi — Atlas, Neon Jamoa, Lavanda, Keynote Oq uslublarida ketma-ket.
2. **Mavzuni mahsulot UI orqali ko‘rsatish** (gapda qo‘shiq — Apple Music pleyeri). Bizda: gapda maosh — bank ilovasi kartasi yoki **ish haqi varaqasi** UI; gapda CRM — CRM oynasi.
